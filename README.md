# framework-pedagogico-ia
Un modelo tecnopedagógico para la creación de **Objetos de Aprendizaje Multimodales e Interactivos (OAMI)** aplicados a la enseñanza de TICs, Economía, Matemáticas y Mercadotecnia.
---

## 🎯 Objetivo General
Integrar la Inteligencia Artificial Generativa y la programación web para sistematizar el diseño curricular por progresiones, traduciendo conceptos abstractos en experiencias interactivas y multimodales.

---

## 🧩 Flujo de Trabajo (Pipeline Didáctico)

1. **Diseño de Progresión:** Estructuración pedagógica mediante Gemini/ChatGPT (`/prompts/01-estructurador-progresiones.md`).
2. **Generación Multimodal:** Síntesis visual y audiovisual (Notebook/Infografías/Slides) (`/prompts/02-generador-guiones-slides.md`).
3. **Desarrollo de Artefacto:** Creación de simuladores e interactivos HTML5/JS (`/prompts/03-generador-artefactos-html.md`).
4. **Despliegue y Práctica:** Publicación directa para estudiantes mediante **GitHub Pages**.

---

## 📚 Marco Pedagógico
* **Diseño Universal para el Aprendizaje (DUA):** Múltiples formas de representación y acción.
* **TPACK & SAMR:** Redefinición tecnológica de la práctica docente.
* **Aprendizaje Activo:** Experimentación guiada en código interactivo.
